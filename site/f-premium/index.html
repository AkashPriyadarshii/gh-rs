Why gh-rs

Small tool, presented properly.

gh does everything. gh-rs does four things and shows its work: real numbers, real output, real file tree.

01 / STARTUP + SIZE

A binary that respects your machine.

Strip plus LTO lands 12.4 MB. --help answers in ~50ms because there is no runtime to warm. Built and tested on the 8GB Windows box it ships from.

gh      40.7 MB · 102ms --help
gh-rs   12.4 MB ·  49ms --help
02 / AGENTS

JSON where it counts.

Every list and view takes --json. Pipe straight to jq.

pr list --json | jq '.[].n'
12  14  19
03 / AUTH

Token out of dotfiles.

Device flow stores in Credential Manager / Keychain. Status prints validity, never the secret.

04 / CODE

Fifteen files. One error enum.

Each command is one cli/ module plus one github/ module. System git for clone fidelity.

Commands

Four groups. --help tells the truth.

--json on list/view only. Mutating commands speak plain text. --limit 1–100, default 30, one per_page request.

$ gh-rs auth login     # browser code → OS keychain
$ gh-rs auth status    → ok
$ gh-rs auth logout    # credential deleted
$ gh-rs repo list --limit 3 [--json]   # newest push first
$ gh-rs repo view [owner/repo]          # bare = git origin
$ gh-rs repo create demo               # private unless --public
$ gh-rs repo clone owner/repo [dir]    # Bearer header auth
$ gh-rs pr create --title T --head feat --base main
→ #12 opened
$ gh-rs pr list / view / diff 12       # diff = raw text
$ gh-rs pr merge 12 --method squash     # merge|squash|rebase
$ gh-rs issue create --title T --body B [--repo o/r]
→ #7 opened
$ gh-rs issue list / view 7 [--json]
$ gh-rs issue close 7

Under the hood

Fifteen files. No magic.

Octocrab typed pulls, raw REST where models overflow the stack, system git for clone fidelity.

src/main.rs       # tokio current_thread entry
src/error.rs      # AppError — every fallible path returns it
src/cli/          # auth repo pr issue — args + dispatch
src/github/       # client auth repo pr issue — API layer
src/git.rs        # subprocess, Bearer extraHeader
src/render.rs     # plain-text view renderers

v0.1 refuses

  • actions, releases, gists, search — full parity ≈ 65 solo-weeks, cut
  • TUI or pager — plain text, no exceptions
  • pagination past --limit 100 — single per_page request
  • --jq engine, JSON on mutating commands
  • panic=abort — backtraces beat ~1MB
